## Concepts Learned

### Prompt Reusability

Reusable prompts help maintain consistency and reduce the effort required to create prompts repeatedly for similar tasks.

### Prompt Categorization

Grouping prompts based on use cases improves accessibility and maintainability.

Examples:

* Email Generation
* Emotion Analysis
* Resume Analysis
* Customer Support

### Prompt Structuring

Well-structured prompts typically include:

* Role
* Context
* Task
* Constraints
* Output Format
