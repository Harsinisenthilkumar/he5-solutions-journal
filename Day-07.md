## Concepts Learned

### Prompt Templates

Prompt templates provide reusable structures that can be customized using dynamic placeholders.

Example:

{%user_input%}
{%role%}
{%task%}

This approach improves flexibility and reusability.

### Prompt Standardization

Standardized prompts ensure consistency across users, teams, and applications.

### Placeholder-Based Prompting

Placeholders allow a single prompt template to support multiple scenarios without modifying the core prompt structure.

### Prompt Repository Management

Prompt repositories serve as centralized collections of reusable prompts that can be maintained, updated, and shared across projects.
